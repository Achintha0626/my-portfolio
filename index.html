Recent Projects

Suwa Manasa

Suwa Manasa - is an AI-powered mental wellness platform that supports children's emotional well-being through AI story generation, drawing-based mood prediction, facial emotion recognition with music recommendations, and voice-based mood detection. As part of the development team, I developed the Sinhala voice-first mood prediction module using Python, FastAPI, Flutter, MongoDB, XLM-RoBERTa, and speech-to-text technologies. The system analyzes spoken responses in real time, predicts emotional states with 96% accuracy, and automatically notifies parents when signs of negative emotions are detected.

Jobify

Jobify - Job Search Tracker Application (MERN Stack) Developed a job search tracking application that helps users monitor their job application progress throughout the month. Built using the MERN stack (MongoDB, Express, React, Node.js), Jobify allows users to log and track the number of job applications they’ve sent each month, keeping detailed records of each application’s status. Features include the ability to set reminders, track responses, and manage application deadlines. Employers and job seekers can also update application statuses, while users can view insightful analytics on their job search progress. The app aims to streamline the job application process, helping users stay organized and motivated during their search..

AI Travel Planner

TripPlanner – Trip Planning Mobile App (React Native, Google Places API, Gemini API, ) I developed TripPlanner as a cross‑platform mobile application that empowers users to discover and customize trips in just a few taps. Leveraging the Google Places API, it provides autocomplete‑powered destination search with filters for region, budget, and interests, while the Gemini API generates AI‑driven, day‑by‑day itineraries—including hotel recommendations, flight estimates, and curated activity suggestions. I crafted a clean, card‑based UI and implemented robust state management with Redux to support offline caching, live updates, and seamless calendar synchronization with in‑app reminders. This project strengthened my expertise in mobile app architecture, real‑time data handling, RESTful API integration, and AI‑driven automation, culminating in a polished, user‑centric travel planning experience.
